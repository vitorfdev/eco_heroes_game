## Como executar o código-fonte
1. Baixe e instale a **Godot Engine 4.7 (versão Standard): https://godotengine.org
2. Clone este repositório ou baixe o `.zip` e extraia os arquivos.
3. Abra a Godot, clique em **Importar** e selecione o arquivo `project.godot` dentro da pasta do projeto.
4. Após abrir o editor, aperte **F5** (ou clique no botão Play) para rodar o jogo.
